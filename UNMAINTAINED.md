# UNMAINTAINED Project List

---

## How Do We Define "Unmaintained"?
A repository is considered unmaintained when it meets all of the following criteria:
- Prolonged lack of commit activity
- No intention from maintainers to continue support
- Zero stars

## How Do We Handle Them?
We take targeted action based on the state of each repository:
1. **Has release tags or production-ready code (GA)**: Archive the repository.
2. **Non-GA code**: Delete the repository.
